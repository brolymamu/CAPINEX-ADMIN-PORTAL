How auto-assignment works

On upload: each customer is assigned only to an agent whose configured locations and loan amount limits match. If no agent matches, that customer stays unassigned. Configure these under Manage Agents → Locations, Minimum loan amount, Maximum loan amount.

Auto Assign Selected (Equal): first select customers, then this button spreads them as evenly as possible across available agents. It does not use location or loan limits.
